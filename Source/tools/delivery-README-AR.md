# JEC | AlJallad Contracting — ملف التسليم

## المحتويات
- `Demo/` نسخة العرض. شغّل `START-DEMO.command` على الماك أو `START-DEMO.cmd` على ويندوز (يحتاج Node.js)، أو افتح `Open-demo.html` مباشرة.
- الموقع يُنشر على Cloudflare من GitHub مباشرة. الخطوات في `Cloudflare-guide.md`.
- `JEC-AlJallad-website-source.zip` المصدر الكامل للموقع مع أدوات التغليف والوثائق والصور الأصلية.
- `Documents/` مصادر المعلومات وأصل كل صورة.

## ما هو تجريبي وما هو حقيقي
- هذه نسخة تجريبية للموافقة.
- المبنى والعمّال والآلات والمدينة والغرفة الداخلية تصوّر معماري بالنمذجة ثلاثية الأبعاد والذكاء الاصطناعي، وليست مشروعاً منفّذاً. الموقع يذكر ذلك بوضوح.
- قسم المشاريع حقيقي: عشرة مشاريع منشورة على حساب @jallad.contracting بأسمائها وروابطها كما هي.

## قبل النشر العام
- موافقة صاحب الشركة على المحتوى.
- إضافة صفحتي سياسة الخصوصية والشروط.
