# الوثائق

- `SOURCES.md` مصادر كل معلومة حقيقية في الموقع.
- `IMAGE-ASSETS.md` مصدر كل صورة وفيديو في الموقع: ما هو حقيقي، وما هو تصوّر بالذكاء الاصطناعي أو Blender.
- `Media-originals/photoreal_stills/` الصور الواقعية الأصلية (2688×1520) التي بُني منها فيلم البناء والتشطيب.

على الماك فقط (لا ترفع على GitHub ولا تدخل ملفات الـ ZIP):
- `Evidence/` صفحات المراجعة (QC) لكل نسخة.
- `Archives/` النسخ القديمة من الموقع (v1، v3، v4)، الأفلام القديمة، مصدر الموقع الأول للشركة، والتجارب الأولى.
